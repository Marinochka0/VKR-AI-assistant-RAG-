<p>Какое определение соответствует методу простой итерации для решения систем линейных уравнений?</p>
{
~Метод с последовательным обновлением компонент, используя актуальные значения на той же итерации
=Приведение системы к эквивалентному виду и построение последовательности приближений x^(k+1) \= B x^(k) + f
~Итерационный процесс с переменными параметрами на основе корней многочлена Чебышева
~Разбиение матрицы на диагональную и треугольные части с релаксационным коэффициентом
}

[html]
<p>Какой смысл имеет метод простой итерации?</p>
{
~Обновление компонент независимо с использованием предыдущих значений итерации
~Ускорение сходимости за счет введения переменных шагов по спектру
~Корректировка в направлении антиградиента с фиксированным параметром
=Каждое приближение получается подстановкой предыдущего в правую часть, сходимость при норме матрицы меньше 1
}

[html]
<p>Какое утверждение верно для приведения системы к эквивалентному виду в методе простой итерации?</p>
{
~Система разбивается на L + D + U, где L — нижняя треугольная часть
~Используется предобуславливание с переменными параметрами τ_k для спектра
=Система преобразуется в x \= B x + f, где B \= I - D^\{-1\} A, D — диагональная часть
~Применяется релаксация с параметром ω > 1 для ускорения
}

[html]
<p>Какое условие сходимости метода простой итерации?</p>
{
~Спектральный радиус матрицы итераций ≥ 1 для дивергенции
=Норма матрицы B < 1 в некоторой матричной норме, согласованной с векторной
~Матрица A должна быть несимметричной без доминирования
~Параметр релаксации ω \= 1 для базового случая
}

[html]
<p>Как оценивается погрешность в методе простой итерации?</p>
{
~Погрешность пропорциональна (1 - ω)^k с релаксацией
=Если ||B|| < q < 1, то погрешность на k-м шаге ≤ q^k / (1 - q) * ||x^(1) - x^(0)||
~Оценка основана на корнях многочлена Чебышева для спектра
~Погрешность уменьшается как 1/k^2 без зависимости от нормы
}

[html]
<p>Какова геометрическая интерпретация метода простой итерации?</p>
{
~Последовательная проекция на гиперплоскости с регулируемым шагом
~Движение с переменными шагами, минимизирующими отклонение на спектре
=Последовательное применение сжимающего отображения в банаховом пространстве, сходимость к фиксированной точке
~Одновременная проекция на все гиперплоскости без сжатия
}

[html]
<p>Какое определение соответствует методу Ричардсона?</p>
{
~Метод с разбиением матрицы на L + D + U и последовательным обновлением
~Итерации с независимым обновлением компонент без спектра
=Градиентный спуск с переменными параметрами по Чебышеву
~Итерационный процесс x^(k+1) \= x^(k) + τ (b - A x^(k)) с постоянным параметром τ для симметричных положительно определённых матриц
}

[html]
<p>В чём смысл Чебышевского итерационного метода?</p>
{
=Развитие метода Ричардсона с переменными параметрами τ_k, выбираемыми на основе корней многочлена Чебышева для ускорения сходимости
~Обновление компонент с использованием предыдущих значений на той же итерации
~Применение постоянного шага τ без оценки спектра матрицы
~Введение релаксации для перерелаксации с фиксированным ω
}

[html]
<p>Какое условие сходимости для метода Ричардсона?</p>
{
~Спектральный радиус > 1 для обеспечения дивергенции
=Параметр τ в (0, 2/λ_max), где λ_max — максимальное собственное значение A
~Матрица A не должна быть положительно определённой
~Параметры τ_k фиксированы без связи с Чебышевым многочленом
}

[html]
<p>Как оценивается погрешность в Чебышевском методе?</p>
{
~Погрешность как q^k, где q \= 1 без зависимости от спектра
~Оценка аналогична Зейделю с ω \= 1 для релаксации
=Сходимость порядка exp(-√κ / 2), где κ — число обусловленности, быстрее Ричардсона
~Погрешность не зависит от спектра и уменьшается линейно
}

[html]
<p>Какова геометрическая интерпретация Чебышевского метода?</p>
{
~Одновременная проекция на гиперплоскости без шага
~Сжимающее отображение без переменного шага
=Движение с переменными шагами τ_k, оптимально "раскачивающееся" между направлениями для быстрого достижения решения
~Проекция с перерелаксацией для ускорения
}

[html]
<p>Какое свойство имеет метод Ричардсона?</p>
{
=Скорость сходимости пропорциональна (λ_max - λ_min)/(λ_max + λ_min)
~Легко параллелизуется как Якоби без спектра
~Использует обновленные значения сразу на итерации
~Требует ω > 1 для ускорения с релаксацией
}

[html]
<p>Какое определение метода Якоби?</p>
{
=Итерационный процесс с разбиением A \= D + L + U и x^(k+1) \= D^\{-1\} (b - (L + U) x^(k))
~Метод с последовательным обновлением и релаксацией
~Ускорение с Чебышевскими параметрами по спектру
~Градиентный спуск с постоянным τ без доминирования
}

[html]
<p>Какой смысл метода Якоби?</p>
{
~Использование актуальных значений на той же итерации
~Релаксация с ω ≠ 1 для перерелаксации
=Обновление компонент независимо, используя значения предыдущей итерации, сходимость при диагональном доминировании
~Введение переменных параметров для спектра матрицы
}

[html]
<p>Какое условие сходимости метода Якоби?</p>
{
~Матрица A симметрична и отрицательно определена
~Параметр τ > 2/λ_max для дивергенции
~Ω \= 1 для базового случая без доминирования
=Спектральный радиус матрицы B \= -D^\{-1\}(L + U) < 1, или строгое диагональное доминирование
}

[html]
<p>Как оценивается погрешность в методе Якоби?</p>
{
=Погрешность ≤ q^k * const, где q \= ||B|| < 1
~Экспоненциально быстрее, как в Чебышевском методе
~Пропорционально (1 - ω)^k с релаксацией
~Независимо от нормы и спектрального радиуса
}

[html]
<p>Какова геометрическая интерпретация метода Якоби?</p>
{
~Одновременная проекция на все гиперплоскости, сходимость к пересечению если сжатие
~Последовательная проекция с шагом ω для релаксации
=Раскачивание с переменными τ_k по спектру
~Фиксированная точка без проекций на плоскости
}

[html]
<p>Какое свойство метода Якоби?</p>
{
~Использует релаксацию ω > 1 для ускорения
~Быстрее Зейделя для всех матриц без исключения
=Легко параллелизуется, поскольку компоненты обновляются независимо
~Требует оценки спектра для τ и шагов
}

[html]
<p>Какое определение метода Зейделя?</p>
{
~Градиентный спуск с τ без последовательности
~Ускорение с Чебышевскими корнями по спектру
~Итерации с независимым обновлением компонент
=Итерационный процесс с последовательным обновлением компонент, используя только что вычисленные значения, на основе A \= L + D + U
}

[html]
<p>Какой смысл метода Зейделя?</p>
{
=Модификация Якоби с использованием актуальной информации для ускорения сходимости
~Введение переменных параметров для спектра матрицы
~Только для несимметричных матриц без доминирования
~Релаксация с ω > 1 для перерелаксации
}

[html]
<p>Какое условие сходимости метода Зейделя?</p>
{
~Ω \= 0 для нулевой релаксации
~τ < 0 для отрицательных шагов
=Спектральный радиус матрицы итераций < 1, или строгое диагональное преобладание, или симметричность и положительная определённость
~Норма > 1 для обеспечения дивергенции
}

[html]
<p>Как оценивается погрешность в методе Зейделя?</p>
{
~Как в Чебышевском, экспоненциально по спектру
~Независимо от q и спектрального радиуса
~Пропорционально k^\{-1\} без зависимости от q
=Погрешность ≤ q^k * const, где q — спектральный радиус матрицы итераций
}

[html]
<p>Какова геометрическая интерпретация метода Зейделя?</p>
{
~Одновременная проекция на гиперплоскости
~Сжатие без проекций на плоскости
~Раскачивание по спектру с переменными шагами
=Процесс последовательной проекции на гиперплоскости, каждая следующая из предыдущей точки
}

[html]
<p>Какое свойство метода Зейделя?</p>
{
=Обычно быстрее Якоби, но труднее параллелизуется
~Медленнее Якоби всегда без исключения
~Требует Чебышевских параметров для спектра
~Использует ω < 1 для подрелаксации
}

[html]
<p>Какое определение метода последовательной релаксации (SOR)?</p>
{
~Базовый градиентный спуск без параметра
=Обобщение Зейделя с параметром ω, x_i^(k+1) \= (1 - ω) x_i^(k) + ω * (обновление по Зейделю)
~С переменными τ_k по Чебышеву
~Независимое обновление как в Якоби
}

[html]
<p>Какой смысл метода SOR?</p>
{
~Упрощение без параметра для базового случая
~Без диагонального преобладания и спектра
=Ускорение Зейделя за счёт параметра ω, оптимально минимизирующего спектральный радиус
~Для неположительных матриц без доминирования
}

[html]
<p>Какое условие сходимости SOR?</p>
{
=Спектральный радиус < 1, для положительно определённых матриц при 0 < ω < 2
~Без симметрии и положительной определённости
~τ \= const без зависимости от ω
~Ω > 2 всегда для перерелаксации
}

[html]
<p>Как оценивается погрешность в SOR?</p>
{
~Как в простой итерации без ω и релаксации
=Погрешность пропорциональна ρ(ω)^k, где ρ минимально при оптимальном ω
~Линейно без зависимости от ρ
~Экспоненциально как в Чебышевском методе
}

[html]
<p>Какова геометрическая интерпретация SOR?</p>
{
~Фиксированная точка без проекций
~Раскачивание с переменными τ_k по спектру
~Одновременная проекция без шага релаксации
=Последовательная проекция с регулируемым шагом ω, перерелаксация при ω > 1
}

[html]
<p>Какое свойство SOR?</p>
{
~Не требует оценки спектра для радиуса
~Медленнее Зейделя при любом ω
=Для симметричных положительно определённых матриц сходится при 0 < ω < 2, оптимальное ω \= 2 / (1 + sqrt(1 - ρ_J^2))
~Параллелизуется как Якоби без последовательности
}

[html]
<p>Какое утверждение верно относительно введения в метод приведения матрицы к форме Хессенберга с помощью преобразований отражения?</p>
{
=Это процесс построения ортогональной матрицы U такой, что H \= U^\{-1\} A U является верхней матрицей Хессенберга с нулями ниже первой поддиагонали
=Метод применяется как предварительный этап перед QR-алгоритмом для снижения вычислительных затрат
~Преобразования Хаусхолдера являются неортогональными, что может привести к потере устойчивости
=Для симметричных матриц результатом является трехдиагональная форма, сохраняющая симметрию
~Алгоритм является итерационным и требует условий сходимости, аналогичных QR-алгоритму
}

[html]
<p>Какие свойства имеет метод приведения к форме Хессенберга?</p>
{
~Завершается за бесконечное число шагов при отсутствии доминирующих собственных значений
=Использует преобразования Хаусхолдера для обнуления поддиагональных элементов по столбцам
=Обеспечивает обратную устойчивость, где вычисленная H близка к точной для возмущенной A
~Для комплексных матриц требует неунитарных преобразований вместо ортогональных
=Сохраняет структуру симметрии, приводя к трехдиагональной матрице для симметричных A
}

[html]
<p>Каковы ключевые аспекты алгоритма приведения к Хессенбергу?</p>
{
=Для каждого столбца k строится вектор Хаусхолдера для обнуления элементов ниже позиции (k+1, k)
~Преобразования применяются только слева, без правого умножения для сохранения подобия
=Вычислительная сложность порядка O(n^3), доминирующая над последующим QR-алгоритмом
=Матрица отражения P \= I - 2 v v^T / (v^T v), где v — вектор Хаусхолдера
~Не сохраняет нули на последующих шагах, требуя дополнительных корректировок
}

[html]
<p>Какие условия и свойства верны для метода Хессенберга?</p>
{
=Универсален для любых квадратных вещественных или комплексных матриц
~Завершается за фиксированное число шагов, не более (n-1) преобразований
=Обратно устойчивый с нормой возмущения порядка машинной точности ε
~Требует итераций до сходимости поддиагональных элементов к нулю
=Служит подготовкой для QR-алгоритма в библиотеках вроде LAPACK
}

[html]
<p>Какова геометрическая интерпретация и практическое значение метода Хессенберга?</p>
{
~Последовательные повороты в плоскостях для диагонализации
=Отражения относительно гиперплоскостей для обнуления проекций столбцов
~Итеративное уточнение базиса без связи с формой Шура
=Обязательный этап для QR-алгоритма, снижая сложность итераций с O(n^3) до O(n^2)
~Применяется только для симметричных матриц без обобщения
}

[html]
<p>Какие утверждения верны для введения в метод вращений (Якоби) для собственных значений симметричной матрицы?</p>
{
=Итерационный алгоритм для нахождения всех собственных значений и векторов симметричной A
~Применим к несимметричным матрицам без потери сходимости
=Строит последовательность ортогональных преобразований, обнуляя наибольший внедиагональный элемент
=Сумма квадратов внедиагональных элементов монотонно уменьшается
=В пределе матрица сходится к диагональной форме с собственными значениями на диагонали
}

[html]
<p>Какие свойства имеет метод вращений?</p>
{
~Сходится только для матриц с кратными собственными значениями
=Численно устойчивый благодаря ортогональным преобразованиям
=Вычислительная сложность O(n^3) на серию, с небольшим числом серий в среднем
~Не вычисляет собственные векторы, только значения
=Одновременно находит собственные векторы через накопление матриц вращений
}

[html]
<p>Каковы условия сходимости и оценка погрешности метода вращений?</p>
{
=Сходится для любой симметричной матрицы без дополнительных условий
=После каждого вращения сумма квадратов внедиагональных элементов уменьшается на 2 a_\{pq\}^2
~Скорость линейная, независимо от стратегии обнуления
=Погрешность в собственных значениях порядка ε при норме внедиагональной части < ε
~Не сходится для матриц с близкими собственными значениями
}

[html]
<p>Какие аспекты алгоритма метода вращений верны?</p>
{
~Матрица вращения в плоскости (p,q) с углом θ, обнуляющим a_\{pq\}
~Угол θ вычисляется как tan(2θ) \= 2 a_\{pq\} / (a_\{pp\} - a_\{qq\})
=Стратегия\: циклический перебор пар или выбор максимального |a_\{pq\}|
=Симметрия сохраняется на всех итерациях
=В случае матрицы с размерностью 2 сходится за одну итерацию
}

[html]
<p>Какова геометрическая интерпретация метода вращений?</p>
{
=Последовательные повороты координат для согласования с главными осями квадратичной формы
=Приведение квадратичной формы к сумме квадратов без "расцепления" переменных
=Повороты в n-мерном пространстве, приближающие к диагональному виду
~Отражения относительно гиперплоскостей, как в Хессенберге
~Итеративное обнуление без связи с эллипсоидом
}

[html]
<p>Какие утверждения верны для введения в QR-алгоритм?</p>
{
=Итерационный метод для нахождения всех собственных значений квадратной матрицы
~Применим только к симметричным матрицам без предварительного приведения
=На каждой итерации QR-разложение A_k \= Q_k R_k, затем A_\{k+1\} \= R_k Q_k
=Последовательность A_k сходится к верхней треугольной форме Шура
=Сохраняет собственные значения за счет подобия A_\{k+1\} \= Q_k^\{-1\} A_k Q_k
}

[html]
<p>Какие свойства QR-алгоритма верны?</p>
{
~Сходится без условий на спектр, даже для кратных значений
=Численно устойчивый благодаря ортогональным преобразованиям
~Без предварительного приведения сложность O(n^2) на итерацию
=С предварительным приведением к Хессенбергу сложность O(n^2) на итерацию
=Лежит в основе библиотек LAPACK, MATLAB для собственных значений
}

[html]
<p>Каковы условия сходимости и стратегия сдвигов в QR-алгоритме?</p>
{
=Сходится при |λ_1| > |λ_2| > ... > |λ_n| для базовой версии
=Сдвиги (например, Уилкинсона) ускоряют сходимость до квадратичной
=Сдвиг σ_k выбирается как собственное значение нижнего 2x2 блока
~Без сдвигов сходимость всегда квадратичная
~Для симметричных матриц не требуется сдвигов
}

<p>Какие аспекты реализации QR-алгоритма для Хессенберга верны?</p>
{
=QR-разложение с помощью (n-1) вращений Гивенса, сложность O(n^2)
~Структура Хессенберга не сохраняется на итерациях
~Без сдвигов сходится только при равных модулях λ_i
=Сдвиг Уилкинсона обеспечивает квадратичную сходимость в среднем
=Дефляция расщепляет задачу при малых поддиагональных элементах
}

<p>Какова геометрическая интерпретация QR-алгоритма?</p>
{
~Последовательные отражения для обнуления столбцов
=Ортогонализация базиса по Граму-Шмидту на каждом шаге
=Перевычисление оператора в новом ортонормированном базисе
~Повороты для диагонализации без базиса
=Выравнивание базиса по инвариантным подпространствам
}

<p>Какие утверждения верны для введения в итерационные методы частичной проблемы собственных значений?</p>
{
=Нахождение нескольких собственных значений и векторов, удовлетворяющих A v \= λ v
=Строят приближения начиная с начального вектора, применяя A или модификации
~Сходятся к минимальным по модулю значениям без сдвигов
=Включают степенную итерацию для доминирующего λ
~Обратная итерация для ближайшего к сдвигу σ
}

[html]
<p>Какие свойства итерационных методов для собственных значений верны?</p>
{
~Применимы только к симметричным матрицам без исключений
~Степенная итерация сходится при |λ_1| \= |λ_2|
=Скорость сходимости степенной итерации \~ |λ_2 / λ_1|^k
=Обратная итерация решает (A - σ I) w \= v, затем нормализация
=Методы подпространств используют ортогонализацию для нескольких векторов
}

[html]
<p>Каковы условия сходимости итер. методов для собственных?</p>
{
=Степенная итерация\: |λ_1| > |λ_i| для i>1, ненулевая проекция на v_1
=Обратная\: сходимость к ближайшему к σ, с проекцией на подпространство
~Не сходится при комплексных λ без сдвигов
~Для всех методов требуется положительная определенность A
=Сдвиг спектра для внутренних значений
}

[html]
<p>Как оценивается погрешность в итерационных методах для собственных?</p>
{
=Для степенной\: ошибка \~ |λ_2 / λ_1|^k
~Независимо от разделения спектра
=Отношение Рэлея для оценки λ\: λ ≈ v^T A v / v^T v
=В методах подпространств ортогонализация Грама-Шмидта
~Линейная сходимость без зависимости от k
}

[html]
<p>Какова геометрическая интерпретация итерационных методов для собственных?</p>
{
~Повороты для диагонализации квадратичной формы
=Усиление компоненты в направлении доминирующего вектора
~Обратная итерация как проекция без усиления
=Сходимость к лучу, порожденному собственным вектором
=Притягивание к подпространству при сдвиге σ
}
